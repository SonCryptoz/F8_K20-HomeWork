    HTML

    HTML là ngôn ngữ cấu trúc nội dung web. Nó giúp bạn tạo tiêu đề, đoạn văn, danh sách, ảnh và nút bấm.

    • Thẻ heading cho tiêu đề
    • Thẻ p cho đoạn văn
    • Thẻ img cho hình ảnh
    • Thẻ ul/li cho danh sách
    <h1>Xin chào</h1>

  <li>HTML</li>

    CSS

    CSS dùng để trang trí giao diện, định dạng màu sắc, khoảng cách, hình ảnh và bố cục.

    • color: màu chữ
    • padding: khoảng cách bên trong
    • border-radius: bo góc
    • display: flex để sắp xếp layout
    .card {
  background: #fff;
  border-radius: 16px;
  padding: 20px;
}

    JavaScript

    JavaScript giúp web tương tác với người dùng, xử lý sự kiện, thay đổi nội dung và thêm hiệu ứng.

    • Thêm sự kiện click
    • Thay đổi DOM
    • Hiển thị dữ liệu động
    • Kiểm tra điều kiện
    const btn = document.querySelector('button');
btn.addEventListener('click', () => {
  console.log('Hello');
});
